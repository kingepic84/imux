The first release of imux, a terminal multiplexer that does images right.

## What it is

Run several shells in one terminal, detach, and pick them up later. Pictures you print stay where they are when you scroll, resize, or split.

- **Pictures.** Images (iTerm2, Sixel, and Kitty graphics) scroll with the text, resize with the pane, and show up in copy mode.
- **Agent status.** See which panes have a coding agent working, waiting for you, or finished.
- **Worktrees.** Open a worktree as its own window with one command.
- **Saved sessions.** Layouts are saved as you work and come back after a restart. `prefix C-s` saves a snapshot and `prefix C-r` brings it back.
- **Plugins.** Extend it with a program in any language.
- **Safe output.** Text a program prints can't change your status line or run commands.

It reads tmux-style configuration and keeps the familiar keys. It is mostly compatible, not a drop-in replacement: run `imux check-config ~/.tmux.conf` to see what carries over.

## Fixed on the way to this release

- A PowerShell pane no longer loses the command typed into it when a saved session is restored: imux waits until PowerShell asks where the cursor is.
- The rolling copies of the autosave no longer skip a copy that was left out for coming too soon: it is written when the interval is over.

## Install

```sh
brew install kingepic84/tap/imux
```

or

```sh
curl -fsSL https://imux.cc/install.sh | bash
```

then run `imux setup` once. That installs the manual and the agent skill, and adds one line to your shell startup file.

## Which file to download

Most people should use Homebrew or the install script above, which pick the right file. To download one by hand, each archive holds the `imux` binary alone, and the `.sha256` next to it is its checksum.

| System | File |
| --- | --- |
| macOS, Apple silicon (M1 and later) | `imux-aarch64-apple-darwin.tar.gz` |
| macOS, Intel | `imux-x86_64-apple-darwin.tar.gz` |
| Linux, 64-bit ARM | `imux-aarch64-unknown-linux-gnu.tar.gz` |
| Linux, 64-bit x86 | `imux-x86_64-unknown-linux-gnu.tar.gz` |

macOS 11 or newer; Linux with glibc 2.28 or newer. More in the install guide: https://docs.imux.cc/start/install/
