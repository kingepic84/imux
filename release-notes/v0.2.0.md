Agents and saved sessions get much better: restored panes keep their agents, their names, and their conversations, and Claude Code sessions have names imux can show and agents can read. Upgrade if you run coding agents in panes or restore sessions after a restart.

## Fixed

- **A started agent keeps its name.** A name given with `imux agent start` was lost when the program replaced its first status report, for example after Claude Code's "trust this folder" dialog. It now stays with the program until it ends, unless you set another name by hand.
- **Restoring after a restart works with the empty session.** A new server starts with an empty session named `0`, which blocked a saved session of the same name ("1 left alone"). A session nobody has used (one pane, nothing typed into it, no agent) now gives way to the saved one, and your client follows it. A session you have used is still left alone.
- **Agents keep control of their panes across a restore.** Panes an agent spawned came back as strangers, so `command-from-panes spawned` refused it. Snapshots now keep who made which pane, and a restore gives the links back (pane numbers still change; use names).
- `imux agent name --help` printed the arguments in the wrong order. The pane comes first: `imux agent name PANE NAME`.
- Skill: it now warns that waiting for text you typed matches your own command, and that `imux events` without `--wait` never ends.

## Added

- **`imux agent session PANE "NAME"`** gives imux the name of a program's own session, such as Claude Code's `/rename`. `imux agent get PANE --json` shows it as `agent_session`, together with `previous_agent_session`. Saying the same name again changes nothing. The agent panel shows the session name for an agent with no name of its own.
- **`imux setup` installs a Claude Code hook** (`~/.claude/imux-claude-hook.sh`). It tells imux each session's name, and at the start of a session it reports `claude --resume SESSION_ID`, so a restored pane continues its own conversation and not the latest one of the folder. If you already have a `~/.claude/settings.json`, imux never edits it: it prints the entries to merge. `--no-claude-hooks` leaves it out and `--claude-dir DIR` picks another directory.

## Good to know

- A new command exists (`api-agent-session`), which is why this is a minor release. No keys, options, or defaults changed.
- Snapshots from older versions load. New snapshots add one window line, `imux.spawn`, which older versions ignore.
- The hook needs your Claude Code hooks updated: run `imux setup` and merge the printed entries. After a restore, a pane's session name can be missing until your next prompt there, and the previous session name starts empty.

## Install or upgrade

```sh
brew upgrade kingepic84/tap/imux
```

or

```sh
curl -fsSL https://imux.cc/install.sh | bash
```

then run `imux setup` again. The running server keeps the old code until it restarts. To switch without losing your layout: press `prefix C-s` to save, run `imux kill-server`, start `imux` again, and press `prefix C-r`.

## Which file to download

Most people should use Homebrew or the install script, which pick the right file. By hand: each archive holds the `imux` binary alone, and the `.sha256` next to it is its checksum.

| System | File |
| --- | --- |
| macOS, Apple silicon (M1 and later) | `imux-aarch64-apple-darwin.tar.gz` |
| macOS, Intel | `imux-x86_64-apple-darwin.tar.gz` |
| Linux, 64-bit ARM | `imux-aarch64-unknown-linux-gnu.tar.gz` |
| Linux, 64-bit x86 | `imux-x86_64-unknown-linux-gnu.tar.gz` |
