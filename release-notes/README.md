# Release notes

One file per release, `vX.Y.Z.md`: the text of the release page on Forgejo and GitHub, in Markdown.
A release cannot be published without it (`scripts/check-release-notes.py`, run by the CI and release
workflows on a tag). Say what changed for the people who use imux: what was fixed, what was added,
what to know when upgrading, and which file to download. Write it before the tag, from the last
release's file.
