Finishes what 0.2.0 started: `imux setup` now sets up Claude Code's hooks for you, even when you already have a settings file, and imux reminds you when setup has not been run. Upgrade if you installed with Homebrew or the plain binary and have not run `imux setup` yet, or if you wanted the Claude Code hook but did not want to merge it by hand.

## Added

- **A reminder when setup is unfinished.** If you attach before running `imux setup` and your shell startup file has no `imux init` line, a box over your panes names the command to run. Escape closes it. It appears once per version of imux, and when you detach, one line says that setup is not finished. It stays quiet when the line is there, when `imux setup` has run (also with `--no-shell`), for a shell `imux init` has no line for, and when the startup file is a symlink (setup leaves those alone). Set `IMUX_NO_SETUP_HINT=1` to turn it off. `imux doctor` has a new `setup` line that says where you are.

## Changed

- **`imux setup` edits an existing `~/.claude/settings.json`.** 0.2.0 only printed the entries for you to merge. Now it adds the hook to the `SessionStart` and `UserPromptSubmit` lists and changes nothing else: your other settings and hooks stay exactly as you wrote them. It also takes out the inline hooks of imux's own from earlier instructions (the ones that run `imux agent name`), so a session is not reported twice. The file as it was is kept once as `settings.json.imux-backup`, and running setup again changes nothing. A file that is not strict JSON (a comment, a trailing comma) is left alone, with the reason and the entries to add yourself.
- Release notes are now a file in the repository for every release, and a release cannot be published without one.

No keys, options, commands, or defaults changed, and saved sessions load as before. `imux setup` now also writes two small files in the state directory (`setup-done` and `setup-hint-seen`), which are what keep the reminder from coming back.

## Install or upgrade

```sh
brew upgrade kingepic84/tap/imux
```

or

```sh
curl -fsSL https://imux.cc/install.sh | bash
```

then run `imux setup`. The running server keeps the old code until it restarts. To switch without losing your layout: press `prefix C-s` to save, run `imux kill-server`, start `imux` again, and press `prefix C-r`.

## Which file to download

Most people should use Homebrew or the install script, which pick the right file. By hand: each archive holds the `imux` binary alone, and the `.sha256` next to it is its checksum.

| System | File |
| --- | --- |
| macOS, Apple silicon (M1 and later) | `imux-aarch64-apple-darwin.tar.gz` |
| macOS, Intel | `imux-x86_64-apple-darwin.tar.gz` |
| Linux, 64-bit ARM | `imux-aarch64-unknown-linux-gnu.tar.gz` |
| Linux, 64-bit x86 | `imux-x86_64-unknown-linux-gnu.tar.gz` |
