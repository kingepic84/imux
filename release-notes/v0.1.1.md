A bug-fix release. Upgrade if you build window names or status text with chained substitutions.

## Fixed

- **Chained substitutions in formats.** `#{s/from/to/;s/from/to/:variable}` (for example in `automatic-rename-format`) gave an empty string. Substitutions joined with `;` now apply left to right, as in tmux.

## Changed

- **Semantic versioning is now enforced in CI.** The version must be valid and never go below a release. The parts people rely on (default keys, option names and defaults, command names, flags, and the plugin and snapshot versions) are checked against the last release: a break needs a new major version (a new minor one while the version is 0.y.z), and an addition needs at least a new minor one.
- The README and the site copy were tidied.

No keys, options, or defaults changed, and saved sessions from 0.1.0 load as before.

## Install or upgrade

```sh
brew upgrade kingepic84/tap/imux
```

or

```sh
curl -fsSL https://imux.cc/install.sh | bash
```

The running server keeps the old code until it restarts. To switch without losing your layout: press `prefix C-s` to save, run `imux kill-server`, start `imux` again, and press `prefix C-r`.

## Which file to download

Most people should use Homebrew or the install script, which pick the right file. By hand: each archive holds the `imux` binary alone, and the `.sha256` next to it is its checksum.

| System | File |
| --- | --- |
| macOS, Apple silicon (M1 and later) | `imux-aarch64-apple-darwin.tar.gz` |
| macOS, Intel | `imux-x86_64-apple-darwin.tar.gz` |
| Linux, 64-bit ARM | `imux-aarch64-unknown-linux-gnu.tar.gz` |
| Linux, 64-bit x86 | `imux-x86_64-unknown-linux-gnu.tar.gz` |
